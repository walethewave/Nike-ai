[SYSTEM NAME] is a three-stage pipeline (Figure~\ref{fig:architecture}):

\subsection{Dialogue}
We use [LLM, e.g.\ Claude Haiku~4.5] with a system prompt instructing
Yor\`ub\'a-only responses. Prior experimentation (a controlled comparison
of English- vs.\ Yor\`ub\'a-language system prompts across three LLM
families, reported separately) found no measurable difference in output
fluency or code-switching rate attributable to system-prompt language;
we therefore use an English-language system prompt for engineering
simplicity, with no measured cost to output quality.\footnote{See the
companion experiment in this project's repository
(\texttt{yoruba-prompt-experiment/RESULTS.md}) for the full methodology
and results, run independently of this system.}
